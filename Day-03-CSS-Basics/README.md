# Day 3 - CSS Basics

## Project: Developer Profile Card

This project is part of my 60 Days Java Full-Stack Journey.

I created a developer profile card and used CSS to control its colors, spacing, layout, typography, and hover effects.

## Concepts Learned

| Concept | Example in `styles.css` | Purpose |
| --- | --- | --- |
| Element selector | `h1 { }` | Styles all heading-one elements. |
| Class selector | `.profile-card { }` | Styles elements using a class name. |
| Descendant selector | `.skills li { }` | Styles list items only inside the skills list. |
| Pseudo-class | `.button:hover { }` | Changes a button when the mouse hovers over it. |
| CSS variables | `--dark-green: #14532d` | Stores reusable colors. |
| Margin | `margin: 1rem` | Adds space outside an element. |
| Padding | `padding: 2rem` | Adds space inside an element. |
| Border | `border: 1px solid` | Draws a line around an element. |
| Border radius | `border-radius: 16px` | Rounds the corners of an element. |
| Box shadow | `box-shadow: ...` | Adds depth below the card. |
| `px` unit | `80px` | Creates a fixed size. |
| `rem` unit | `2rem` | Creates scalable text and spacing. |
| Percentage unit | `width: 100%` | Uses the width of the parent element. |

## Box Model

Every HTML element is a box:

```text
Margin → Border → Padding → Content
```

- Margin: space outside the box
- Border: line around the box
- Padding: space inside the box
- Content: text, image, or other visible information
